2. Chapter — Patterns in Mathematics

nth odd number CBSE-C6-AR-001

nth odd number = 2n − 1

Odd numbers form 1, 3, 5, 7, … The 8th odd number is 2×8 − 1 = 15.

nth even number CBSE-C6-AR-002

nth even number = 2n

Even numbers form 2, 4, 6, 8, … The 9th even number is 2×9 = 18.

nth triangular number CBSE-C6-AR-003

T_n = n(n + 1)/2

Dots in a triangle: 1, 3, 6, 10, 15, … T_5 = 5×6/2 = 15. Lesson content only — no Try It preset.

nth square number CBSE-C6-AR-004

S_n = n²

Square numbers are 1, 4, 9, 16, 25, … The 6th square number is 6² = 36.

nth cube number CBSE-C6-AR-005

C_n = n³

Cube numbers are 1, 8, 27, 64, … The 4th cube number is 4³ = 64. Pattern only, not a volume formula.

Fibonacci sequence rule CBSE-C6-AR-006

F_n = F_{n−1} + F_{n−2} (with F_1 = 1, F_2 = 1)

Each term is the sum of the two before it: 1, 1, 2, 3, 5, 8, 13, … Lesson content only — no Try It preset.

Example A — Odd-number pattern

Find the 12th odd number.

a_12 = 2×12 − 1 = 23.

23

3. Chapter — Number Play

Place value of a digit CBSE-C6-AR-007

Place value = digit × value of its place

Face value is the digit itself; place value depends on position. In 4582 the place value of 5 is 5 × 100 = 500.

Expanded form of a number CBSE-C6-AR-008

Number = sum of (each digit × its place value)

Example: 3406 = 3×1000 + 4×100 + 0×10 + 6×1 = 3000 + 400 + 6.

Example B — Place value

Find the place value of 7 in 7305.

7 is in the thousands place: 7 × 1000 = 7000.

7000

4. Chapter — Prime Time

Factor relation CBSE-C6-AR-009

If a is a factor of b, then b = a × k for some whole number k

A factor divides exactly. 4 is a factor of 20 because 20 = 4 × 5. 1 is a factor of every whole number.

Multiple relation CBSE-C6-AR-010

Multiples of a = a, 2a, 3a, 4a, …

Multiples of 5 include 5, 10, 15, 20, …

Divisibility rule for 2 CBSE-C6-AR-011

A number is divisible by 2 if its ones digit is 0, 2, 4, 6 or 8

148 ends with 8, so it is divisible by 2. Lesson content only — no dedicated Try It preset.

Divisibility rule for 3 CBSE-C6-AR-012

A number is divisible by 3 if the sum of its digits is divisible by 3

For 252: 2+5+2=9, and 9 is divisible by 3. Lesson content only.

Divisibility rule for 5 CBSE-C6-AR-013

A number is divisible by 5 if its ones digit is 0 or 5

680 ends with 0, so it is divisible by 5. Lesson content only.

Divisibility rule for 9 CBSE-C6-AR-014

A number is divisible by 9 if the sum of its digits is divisible by 9

For 729: 7+2+9=18, and 18 is divisible by 9. Lesson content only.

Divisibility rule for 10 CBSE-C6-AR-015

A number is divisible by 10 if its ones digit is 0

940 ends with 0, so it is divisible by 10. Lesson content only.

HCF × LCM relation (two numbers) CBSE-C6-AR-016

HCF(a, b) × LCM(a, b) = a × b

For 12 and 18: HCF=6, LCM=36. Check: 6×36=216 and 12×18=216.

Example C — Factors

Is 6 a factor of 42?

42 = 6 × 7, remainder 0.

Yes

Example D — HCF and LCM

If HCF(8, 12) = 4, find LCM(8, 12).

LCM = (8×12)/4 = 24.

24

5. Chapter — The Other Side of Zero

Absolute value CBSE-C6-AR-022

|a| = distance of a from 0 on the number line

Absolute value is never negative. |−7| = 7 and |7| = 7.

Additive inverse CBSE-C6-AR-023

a + (−a) = 0

The additive inverse of 9 is −9 because 9+(−9)=0. The inverse of 0 is 0.

Integer addition on the number line CBSE-C6-AR-024

Add +k → move k units right; add −k → move k units left

Start at 3; add −5 → move 5 left → −2. So 3+(−5)=−2.

Example E — Integer addition

Using the number line, find (−2)+6.

Start at −2; move 6 units right.

4

7. Common mistakes

Place value is not the same as face value — the digit 5 in 4582 is 500, not 5.

A factor divides exactly; a multiple is the original number times 1, 2, 3, …

HCF × LCM = product only for two numbers.

Absolute value is a distance from zero, so it is never negative.

Adding a negative integer moves left on the number line, not right.
