2. Chapter 1 — Introduction to Algebra

Variable and constant CBSE-C6-AL-001

A variable is a letter that stands for a number; a constant is a fixed number.

In 5x + 3, x is a variable (it can take different values). 5 and 3 are constants (they stay the same). Letters such as x, a, or n are common variables in Class 6.

Algebraic expression CBSE-C6-AL-002

An algebraic expression is a combination of variables, constants and operations.

2x + 7 is an algebraic expression. It uses a variable (x), constants (2 and 7), and operations (multiply, add). An expression does not have an “=” to solve; it is a phrase, not a full sentence.

Like terms CBSE-C6-AL-003

Like terms have the same variable raised to the same power (e.g. 2a and 3a).

2a and 5a are like terms: both are “lots of a”. You may add or subtract them.

Unlike terms CBSE-C6-AL-004

Unlike terms have different variables or powers (e.g. 2a and 3b).

2a and 3b are unlike terms. 2a and 3 are also unlike (one has a, one does not). Unlike terms stay separate; do not add their coefficients.

Combine like terms CBSE-C6-AL-005

pa ± qa = (p ± q)a

Add or subtract the coefficients only, and keep the common variable. 2a + 3a = 5a. 5m − 2m = 3m.

Evaluate an expression CBSE-C6-AL-006

Substitute the given value of the variable and simplify.

If x = 4, then 2x + 3 = 2 × 4 + 3 = 11. First replace the letter, then compute with the usual order of operations.

Example A — Variable and constant

In 5x + 3, name the variable and the constants.

x can change, so it is the variable. 5 and 3 are fixed numbers.

Variable: x. Constants: 5 and 3.

Example B — Algebraic expression

Is 2x + 7 an algebraic expression?

It combines the variable x with constants using multiplication and addition. There is no “=”.

Yes — 2x + 7 is an algebraic expression.

Example C — Like and unlike terms

Are 2a and 5a like terms? Are 2a and 3b like terms?

2a and 5a both have the variable a, so they are like. 2a and 3b have different variables, so they are unlike.

2a and 5a are like. 2a and 3b are unlike.

Example D — Combine like terms

Simplify 2a + 3a.

Both terms have a. Add the coefficients: 2 + 3 = 5. Keep a.

5a

Example E — Combine like terms

Simplify 5m − 2m.

Both terms have m. Subtract coefficients: 5 − 2 = 3.

3m

Example F — Evaluate an expression

If x = 4, find the value of 2x + 3.

Replace x by 4: 2 × 4 + 3 = 8 + 3.

11

3. Chapter 2 — Simple Equations

Equation — two expressions joined by “=”. Both sides have the same value.

Solution — the number that makes the equation true when substituted.

Balance — an equation stays true if you do the same fair operation to both sides.

Simple linear equation (one variable) CBSE-C6-AL-007

ax + b = c (a ≠ 0)

First degree in one variable only. a is the coefficient of x, b is a constant on the left, c is the constant on the right. Example: 2x + 3 = 11.

Addition / subtraction property of equality CBSE-C6-AL-008

If a = b, then a ± k = b ± k

Add the same number to both sides, or subtract the same number from both sides. From 2x + 3 = 11, subtract 3: 2x = 8.

Multiplication / division property of equality CBSE-C6-AL-009

If a = b and k ≠ 0, then a × k = b × k and a ÷ k = b ÷ k

Multiply or divide both sides by the same non-zero number. From 2x = 8, divide by 2: x = 4. Never divide by zero.

Missing number problem CBSE-C6-AL-010

Find the unknown that makes the number sentence true.

Find □ in □ + 5 = 12. The missing number is 7, because 7 + 5 = 12. A box, a blank, or a letter can stand for that unknown.

Example G — Simple linear equation

Solve 2x + 3 = 11.

Subtract 3 from both sides: 2x = 8. Divide both sides by 2.

x = 4 (check: 2 × 4 + 3 = 11).

Example H — Addition / subtraction property

Solve x + 5 = 12.

Subtract 5 from both sides so the x term is alone: x = 12 − 5.

x = 7

Example I — Multiplication / division property

From 2x = 8, find x.

Divide both sides by 2 (the coefficient of x).

x = 4

Example J — Missing number

Find □ in □ + 5 = 12.

What number plus 5 makes 12? 12 − 5 = 7. Check: 7 + 5 = 12.

Missing number = 7

4. What this Class 6 page covers

  • Variable and constant — name the letter and the fixed numbers in an expression.
  • Algebraic expression — a combination of variables, constants, and operations (no “=” to solve).
  • Like and unlike terms — same variable part versus different variable parts.
  • Combine like terms — 2a + 3a = 5a; 5m − 2m = 3m.
  • Evaluate — substitute a given value (e.g. 2x + 3 when x = 4).
  • Simple linear equation — solve ax + b = c (e.g. 2x + 3 = 11).
  • Balance properties — add/subtract or multiply/divide the same non-zero number on both sides.
  • Missing number — find □ (or ?) that makes a number sentence true.

5. Common mistakes

Do not add unlike terms. 2a + 3b is not 5ab and is not 5a.

An expression such as 2x + 7 is not an equation. There is nothing to “solve” until you see “=”.

When you evaluate, replace the letter first, then calculate. Do not add 2 + 3 and then multiply by x.

Whatever you add, subtract, multiply, or divide, do it on both sides of an equation.

Do not divide by zero. The coefficient a in ax + b = c must not be 0.

After solving, substitute the answer back into the original equation to check.
