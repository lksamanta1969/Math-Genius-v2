2. Chapter 1 — Simple Equations

Equation — two expressions joined by “=”. Both sides have the same value.

Variable — the unknown letter we solve for (usually x).

Solution — the number that makes the equation true when substituted.

Balance rule — whatever you add, subtract, multiply, or divide on one side, do the same on the other side.

Simple linear equation CBSE-C7-AL-001

ax + b = c (a ≠ 0)

First degree in one variable only. a is the coefficient of x, b is a constant term, c is the constant on the other side.

Transposition CBSE-C7-AL-002

Moving a term to the other side changes its sign

x + 5 = 12 becomes x = 12 − 5. Adding 5 on the left is the same as subtracting 5 on the right.

From a sentence to an equation

“5 more than a number is 12” → x + 5 = 12. “3 times a number plus 4 is 19” → 3x + 4 = 19.

Check: put the solution back into the original equation. If both sides match, it is correct.

Example A — Linear equation

Solve 3x + 4 = 19.

Subtract 4 from both sides: 3x = 15. Divide both sides by 3.

x = 5 (check: 3 × 5 + 4 = 19).

Example B — Transposition

Solve x + 5 = 12.

Move +5 to the right; the sign changes: x = 12 − 5.

x = 7

Example C — Constant on the left

Solve 7 + x = 10.

Transpose 7: x = 10 − 7.

x = 3

3. Chapter 2 — Algebraic Expressions

Term — a number, a variable, or their product (3x, −2m, 7).

Coefficient — the numerical factor of a term (in 5m the coefficient is 5).

Like terms — same variable part (5m and −2m). Unlike terms cannot be combined (3x and 4).

Expression — a sum or difference of terms. An expression is not an equation (no “=” to solve).

Combine like terms CBSE-C7-AL-003

pa ± qa = (p ± q)a

Add or subtract coefficients only. 5m − 2m = 3m; 2a + 3a = 5a.

Distributive law CBSE-C7-AL-007

a(b + c) = ab + ac

Multiply the factor outside by every term inside the bracket. 3(x + 4) = 3x + 12. The same idea works for a(b − c) = ab − ac.

Degree of an expression (one variable) CBSE-C7-AL-004

Degree = highest power of the variable in the expression

Degree of 4x³ − x + 7 is 3. A non-zero constant such as 7 has degree 0. Class 7 only asks you to read the degree — not to use Class 9 polynomial theorems.

Value of an expression

Replace the variable by a given number and compute. For 2x + 3 when x = 4: 2 × 4 + 3 = 11.

Example D — Like terms

Simplify 5m − 2m.

Both terms have m. Coefficients: 5 − 2 = 3.

3m

Example E — Distributive law

Expand 3(x + 4).

3 × x = 3x and 3 × 4 = 12.

3x + 12

Example F — Degree

Find the degree of 4x³ − x + 7.

Powers of x are 3, 1, and 0. The highest is 3.

Degree = 3

Example G — Substitution

Evaluate 2x + 3 when x = 4.

2 × 4 + 3 = 8 + 3.

11

4. Chapter 3 — Exponents and Powers

Base and exponent — in am, a is the base and m is the exponent (how many times a is multiplied by itself).

Same base only — the product and quotient rules below apply when the bases are identical and non-zero.

Product rule CBSE-C7-AL-005

am × an = am+n

Multiply same base → add exponents. 2³ × 2⁴ = 2⁷ = 128.

Quotient rule CBSE-C7-AL-006

am ÷ an = am−n (a ≠ 0)

Divide same base → subtract exponents. 5⁶ ÷ 5² = 5⁴ = 625.

Do not add the bases. 2³ × 2⁴ is not 4⁷. Class 8 goes further (negative exponents, (ab)n, am ÷ an with more identities) — those are not on this page.

Example H — Product rule

Simplify 2³ × 2⁴.

Same base 2: add exponents 3 + 4 = 7. Then 2⁷ = 128.

2⁷ = 128

Example I — Quotient rule

Simplify 5⁶ ÷ 5².

Same base 5: subtract exponents 6 − 2 = 4. Then 5⁴ = 625.

5⁴ = 625

5. Supported Class 7 question types

  • Simple linear equation — solve ax + b = c (e.g. 3x + 4 = 19).
  • Transposition — move a term and change its sign (e.g. x + 5 = 12).
  • Combine like terms — simplify 5m − 2m or 2a + 3a.
  • Evaluate an expression — substitute a given value (e.g. 2x + 3 when x = 4).
  • Degree — read the highest power in a one-variable expression (worked examples).
  • Distributive law — expand a(b + c) (worked examples).
  • Laws of exponents — product and quotient of the same base (worked examples).

The interactive engine solves one-variable linear equations, like-term simplification, and substitution. Expanding brackets, degree, and exponent laws are taught as worked examples. Not on this Class 7 page: quadratic equations, simultaneous equations, inequalities, Class 8 algebraic identities, or Class 9 polynomials.
