2. Chapter 1 — Polynomials

Polynomial in one variable — an expression of the form anxn + … + a1x + a0, where the powers of x are whole numbers and the coefficients are real numbers.

Term / coefficient — each akxk is a term; ak is its coefficient. The leading coefficient an is the coefficient of the highest power that is not zero.

Constant polynomial — a non-zero number with no variable, such as 7. The zero polynomial is the polynomial that is identically 0.

Degree of a polynomial CBSE-C9-AL-001

deg(p) = highest power of x with a non-zero coefficient

If p(x) = anxn + … + a0 with an ≠ 0, then deg(p) = n. A non-zero constant polynomial has degree 0. The zero polynomial is not assigned a degree in Class 9.

Zero of a polynomial CBSE-C9-AL-002

p(α) = 0

A number α is a zero of p(x) if substituting x = α makes the polynomial equal to zero. Finding a zero is not the same as solving a Class 10 quadratic equation by formula.

Remainder theorem CBSE-C9-AL-003

If p(x) is divided by (x − a), then remainder = p(a)

In full: p(x) = (x − a) q(x) + p(a). The divisor must be linear of the form x − a. If the divisor is x + a, rewrite it as x − (−a) and evaluate p(−a).

Factor theorem CBSE-C9-AL-004

(x − a) is a factor of p(x) ⇔ p(a) = 0

This is the remainder theorem when the remainder is zero. Use it to test a proposed linear factor; do not treat it as a method for Class 10 factorisation of quadratics as a separate chapter.

Example A — Degree

Find the degree of p(x) = 4x3 − 2x + 7.

The powers of x with non-zero coefficients are 3, 1, and 0. The highest is 3, so p is a cubic polynomial.

deg(p) = 3

Example B — Zero of a polynomial

Show that 2 is a zero of p(x) = x − 2.

p(2) = 2 − 2 = 0. So 2 is a zero of p(x).

p(2) = 0

Example C — Remainder theorem

Find the remainder when p(x) = x2 + 3x + 2 is divided by (x − 1).

Remainder = p(1) = 12 + 3(1) + 2 = 1 + 3 + 2 = 6.

Remainder = 6

Example D — Factor theorem

Is (x − 2) a factor of p(x) = x2 − 5x + 6?

p(2) = 4 − 10 + 6 = 0, so (x − 2) is a factor. Indeed p(x) = (x − 2)(x − 3).

(x − 2) is a factor

Class 9 algebraic identities — these expand or factor expressions using cubes and three-term sums. They are not a return to Class 8 square identities (a + b)2 and (a − b)2 as the main lesson.

Square of a trinomial CBSE-C9-AL-005

(x + y + z)2 = x2 + y2 + z2 + 2xy + 2yz + 2zx

The square of a three-term sum is the sum of the three squares plus twice each pairwise product.

Cube of a sum CBSE-C9-AL-006

(x + y)3 = x3 + y3 + 3xy(x + y)

Equivalently, (x + y)3 = x3 + 3x2y + 3xy2 + y3.

Cube of a difference CBSE-C9-AL-007

(x − y)3 = x3 − y3 − 3xy(x − y)

Equivalently, (x − y)3 = x3 − 3x2y + 3xy2 − y3.

Sum of cubes CBSE-C9-AL-008

x3 + y3 = (x + y)(x2 − xy + y2)

Linked to the cube-of-a-sum identity.

Difference of cubes CBSE-C9-AL-009

x3 − y3 = (x − y)(x2 + xy + y2)

This is the Class 9 cube analogue of the Class 8 difference of squares; the square identity itself is not taught again here.

Sum of cubes of three terms CBSE-C9-AL-010

x3 + y3 + z3 − 3xyz = (x + y + z)(x2 + y2 + z2 − xy − yz − zx)

If x + y + z = 0, then x3 + y3 + z3 = 3xyz.

Example E — Square of a trinomial

Check (1 + 2 + 3)2 using the identity.

Left side: 62 = 36. Right side: 1 + 4 + 9 + 2(1)(2) + 2(2)(3) + 2(3)(1) = 14 + 4 + 12 + 6 = 36.

Both sides = 36

Example F — Cube of a sum

Expand (2 + 1)3 using (x + y)3 = x3 + y3 + 3xy(x + y).

23 + 13 + 3(2)(1)(2 + 1) = 8 + 1 + 18 = 27, and (3)3 = 27.

27

Example G — Cube of a difference

Expand (3 − 1)3 using (x − y)3 = x3 − y3 − 3xy(x − y).

33 − 13 − 3(3)(1)(3 − 1) = 27 − 1 − 18 = 8, and 23 = 8.

8

Example H — Sum of cubes

Factor 23 + 33.

23 + 33 = 8 + 27 = 35, and (2 + 3)(4 − 6 + 9) = 5 × 7 = 35.

(2 + 3)(4 − 6 + 9) = 35

Example I — Difference of cubes

Factor 33 − 23.

27 − 8 = 19, and (3 − 2)(9 + 6 + 4) = 1 × 19 = 19.

(3 − 2)(9 + 6 + 4) = 19

Example J — Three cubes

For x = 1, y = 2, z = 3, check x3 + y3 + z3 − 3xyz.

1 + 8 + 27 − 18 = 18. Factor form: (1 + 2 + 3)(1 + 4 + 9 − 2 − 6 − 3) = 6 × 3 = 18.

18

3. Chapter 2 — Linear Equations in Two Variables

Two variables — here the unknowns are x and y together. Class 7 solved ax + b = c in one variable; Class 9 writes a first-degree equation in both x and y.

Graph — every solution (x, y) is a point. All such points lie on a straight line. This page does not solve a pair of linear equations (simultaneous equations) — that is Class 10.

Linear equation in two variables CBSE-C9-AL-011

ax + by + c = 0 (a and b not both zero)

First degree in x and y. Any equation that can be rewritten in this form is linear in two variables. The graph of ax + by + c = 0 is a straight line.

Solution of a linear equation in two variables CBSE-C9-AL-012

(x0, y0) is a solution ⇔ a x0 + b y0 + c = 0

An ordered pair that satisfies the equation is a solution. There are infinitely many solutions; each is a point on the line. Do not confuse one equation with a pair of simultaneous equations.

Line parallel to the y-axis CBSE-C9-AL-013

x = a

Vertical line through (a, 0). Every point on this line has x-coordinate a. In standard form: 1·x + 0·y − a = 0.

Line parallel to the x-axis CBSE-C9-AL-014

y = b

Horizontal line through (0, b). Every point on this line has y-coordinate b. In standard form: 0·x + 1·y − b = 0.

Example K — Standard form

Write 2x + 3y = 6 in the form ax + by + c = 0 and name a, b, c.

2x + 3y − 6 = 0, so a = 2, b = 3, c = −6. Neither a nor b is zero, so the equation is linear in two variables.

2x + 3y − 6 = 0

Example L — Checking a solution

Is (2, 3) a solution of x + y − 5 = 0?

2 + 3 − 5 = 0, so yes. Another solution is (0, 5), because 0 + 5 − 5 = 0. Infinitely many other pairs also work, such as (1, 4).

(2, 3) and (0, 5) are solutions

Example M — Vertical line

Describe the graph of x = 3.

Every point has x-coordinate 3: (3, 0), (3, 1), (3, −2), … . The line is parallel to the y-axis.

x = 3, parallel to the y-axis

Example N — Horizontal line

Describe the graph of y = −2.

Every point has y-coordinate −2: (0, −2), (1, −2), (−3, −2), … . The line is parallel to the x-axis.

y = −2, parallel to the x-axis

4. What this Class 9 page covers

  • Degree — read the highest power with a non-zero coefficient (including degree 0 for a non-zero constant).
  • Zero of a polynomial — check p(α) = 0 by substitution.
  • Remainder theorem — remainder when dividing by (x − a) is p(a).
  • Factor theorem — (x − a) is a factor if and only if p(a) = 0.
  • Class 9 identities — (x + y + z)2, cubes of a binomial, sum/difference of cubes, and x3 + y3 + z3 − 3xyz.
  • Linear equation in two variables — write ax + by + c = 0 and recognise a line.
  • Solutions — test ordered pairs; there are infinitely many solutions to one equation.
  • Axis-parallel lines — x = a (vertical) and y = b (horizontal).

There is no interactive solver on this page. Polynomial division, remainder/factor checks, cube identities, and two-variable equations are shown as worked examples only. Not on this page: Class 8 square identities as a chapter, Class 10 quadratics, simultaneous equations, AP, GP, or calculus.

5. Common mistakes

Do not assign a degree to the zero polynomial in Class 9.

For remainder when dividing by x + a, evaluate p(−a), not p(a).

p(a) = 0 is required for (x − a) to be a factor; a non-zero remainder means it is not a factor.

One linear equation in x and y has infinitely many solutions. Two equations together (a system) is Class 10 work.

x = a is vertical (parallel to the y-axis). y = b is horizontal (parallel to the x-axis). Mixing these is a common graphing error.
