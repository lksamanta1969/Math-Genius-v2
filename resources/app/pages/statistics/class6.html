2. Organising and presenting data

Data — a collection of observations (scores, marks, favourite colours, counts, …).

Observation — one value in the data set.

Tally marks — grouped strokes used while counting; they are usually bundled in fives.

Organise — sort the raw list into values and how often each appears.

Present — show the organised data as a table, a pictograph, or a bar graph so someone else can read it.

3. Chapter — Data Handling and Presentation

Frequency CBSE-C6-DH-001

Frequency of an item = number of times it occurs in the data

Tally marks help count how often each value appears; that count is the frequency. In {2, 3, 2, 2, 5}, the frequency of 2 is 3. A frequency table lists each distinct value beside its frequency (and tallies when helpful).

Pictograph scale CBSE-C6-DH-002

Actual value = (number of symbols) × (value of one symbol)

In a pictograph, each picture stands for a fixed number of items. Always read the key (scale) first. If 1 symbol = 5 books and there are 7 symbols, the total is 35 books.

Bar graph reading CBSE-C6-DH-003

Value = (bar height in axis units) × (scale of the axis)

A bar graph uses bars of equal width; bar length represents the value for each category. If 1 unit = 10 students and a bar has height 4 units, the actual count is 40 students.

Example A — Frequency table

Make a frequency table for the data: 2, 3, 2, 2, 5.

2 appears three times; 3 appears once; 5 appears once.

2: 3; 3: 1; 5: 1

Example B — Frequency of one value

In {2, 3, 2, 2, 5}, what is the frequency of 2?

Count how many times 2 occurs: three times.

Frequency of 2 = 3

Example C — Pictograph

In a pictograph, 1 symbol = 5 books. There are 7 symbols. How many books?

Actual value = 7 × 5.

35 books

Example D — Bar graph

In a bar graph, 1 unit = 10 students. The bar for Class 6 has height 4 units. How many students?

Value = 4 × 10.

40 students

5. Common mistakes

Always read the pictograph key or the bar-graph scale before you multiply.

Frequency is a count of how often a value appears — not the value itself.

In a frequency table, list every distinct value that occurs; do not skip a value that appears only once.

Bar width should be the same for every category; the height (or length) carries the value.

Do not use this page for mean, median, mode, or range. Those are Class 7.
