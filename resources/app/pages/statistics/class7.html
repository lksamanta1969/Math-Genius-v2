Data Handling & Statistics

Class 7

Introductory data handling and statistics for CBSE Class 7 — mean, median, mode, range, frequency tables, pictographs, and bar graphs. Worked examples and the interactive section below use the same offline Statistics engine as the AI Math Solver (Phase 8E).

1. Data handling basics

Data — a collection of observations (scores, marks, heights, counts, …).

Observation — one value in the data set.

Frequency — how many times a value appears.

Tally marks — grouped counts (||||/) used when building a frequency table.

Pictograph — data shown with symbols; read the scale (e.g. 1 symbol = 5 books).

Bar graph — compare categories using bar heights; read the unit scale on the axis.

2. Key formulas

Mean (average) CBSE-C7-ST-001

Mean = (sum of observations) ÷ (number of observations)

Range CBSE-C7-ST-002

Range = highest value − lowest value

Median CBSE-C7-ST-003

Arrange data in order; median is the middle value (or average of the two middle values).

Mode CBSE-C7-ST-004

Mode = the value that occurs most often

Frequency table CBSE-C6-DH-001

List each value with its frequency (and tally marks when helpful).

Pictograph value CBSE-C6-DH-002

Total = (number of symbols) × (value per symbol)

Bar graph value CBSE-C6-DH-003

Total = (bar height in units) × (value per unit), when a scale is given

3. Supported Class 7 question types

  • Mean — find the average of a list of numbers.
  • Median — find the middle value after arranging data.
  • Mode — find the most frequent value (or “no mode” if all appear once).
  • Range — find highest minus lowest (needs at least two observations).
  • Frequency table — count how often each value appears.
  • Frequency of one value — e.g. “frequency of 2 in the data …”.
  • Pictograph — scale + number of symbols → actual total.
  • Bar graph — bar height (and unit scale) → actual total.

Advanced topics such as standard deviation, variance, pie charts, histograms, box plots, and regression are not supported on this Class 7 page.

4. Worked examples

Example A — Mean

Find the mean of the data: 5, 8, 6, 7, 9.

Sum = 5 + 8 + 6 + 7 + 9 = 35. Number of observations = 5.

Mean = 35 ÷ 5 = 7

Example B — Median

Find the median of 3, 8, 5, 2, 9.

Ascending order: 2, 3, 5, 8, 9. Middle value (3rd of 5) = 5.

Median = 5

Example C — Mode

Find the mode of 2, 3, 2, 5, 2, 4.

2 appears three times — more than any other value.

Mode = 2

Example D — Range

Find the range of the data 3, 8, 5, 12, 7.

Highest = 12, lowest = 3.

Range = 12 − 3 = 9

Example E — Frequency table

Make a frequency table for the data: 2, 3, 2, 2, 5.

2 → 3 times; 3 → 1 time; 5 → 1 time.

2: 3; 3: 1; 5: 1

Example F — Bar graph

In a bar graph, 1 unit = 10 students. The bar for Class 6 has height 4 units.

Students = 4 × 10 = 40

Example G — Pictograph

In a pictograph, 1 symbol = 5 books. There are 7 symbols.

Books = 7 × 5 = 35
